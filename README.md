# TrueCombat: Platinum — Dev Builds

Dev testing builds of TrueCombat: Platinum. These are **not the live game**.

- Each build carries a DEV BUILD watermark and is versioned `x.y.z-devN`.
- Install every dev build into its own folder, separate from the live game.
- Dev builds ship without Easy Anti-Cheat and cannot join official servers.
- Each release includes its corresponding source code.
